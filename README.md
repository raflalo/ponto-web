# Ponto+ Web

Interface web do Ponto+, um sistema pessoal para registrar e acompanhar a jornada de trabalho. O projeto foi desenvolvido com HTML, CSS e JavaScript, sem frameworks ou processo de build.

## Requisitos

- Chrome ou Firefox atualizado
- Ponto+ API instalada e em execução

## Instalação

Este projeto não possui dependências para a execução. Após baixar ou clonar o repositório:

1. Instale e inicie a Ponto+ API seguindo as instruções do repositório `ponto-api`.
2. Confirme que a API está disponível em `http://127.0.0.1:5001/api/health`.
3. Abra o arquivo `index.html` deste projeto no navegador.

## Execução

Não é necessário iniciar um servidor para o front-end. Com a API em execução, abra o `index.html` diretamente no Chrome ou Firefox.
